# Sound files

Upload any of these files to this folder. No code change is required:

- `sms.m4a`, `sms.mp3`, or `sms.wav`
- `kakao.m4a`, `kakao.mp3`, or `kakao.wav`
- `ringtone.m4a`, `ringtone.mp3`, or `ringtone.wav`

When more than one extension exists for the same sound, the player tries M4A, MP3, then WAV.
