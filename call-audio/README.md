# 通话音频上传规则

音频文件上传到 GitHub 仓库 `call-audio/` 文件夹。**一条台词一个文件，文件名按通话里第几句编号（从 01 开始，双方的台词都计入序号）。**

## 선우（双方都有音频）
你上传的 7 个文件都是 M4A，网页已按 M4A 文件名读取，无须转换格式：

- `sunwoo-01.m4a` — 선우：여보세요
- `sunwoo-02.m4a` — 李在贤：야
- `sunwoo-03.m4a` — 선우：형 왜
- `sunwoo-04.m4a` — 李在贤：어디 아직 안왔어?다들 기다려
- `sunwoo-05.m4a` — 선우：나 왔는데
- `sunwoo-06.m4a` — 李在贤：아 그래? 잘했어
- `sunwoo-07.m4a` — 선우：이 미친…

## xxx（只有李在贤有音频）
当前网页使用 M4A，保留以下文件名与格式：`xxx-01.m4a`、`xxx-03.m4a`、`xxx-05.m4a`、`xxx-07.m4a`。其余 xxx 台词只显示文字。

## 영재（只有李在贤有音频）
当前网页使用 MP3：`youngjae-01.mp3`、`youngjae-03.mp3`、`youngjae-05.mp3`、`youngjae-07.mp3`；英宰台词只显示文字。

## 交互规则
点击通话屏幕显示下一句并播放匹配的音频；点击下一句会停止上一句音频。最后一句播放结束后自动挂断。没有上传的文件仍显示文字，并可继续点下一句。

如果已有音频是 M4A，请使用真正的音频转换方式转为 MP3；不能仅修改扩展名。

## EP003 后自动来电：영재（双方逐句音频）

EP003 结束后会显示 영재 来电界面。接听后点击屏幕逐句显示台词并播放对应音频。请上传 M4A 文件：

- `ep003-youngjae-01.m4a` — 영재：형
- `ep003-youngjae-02.m4a` — 현재：왜
- `ep003-youngjae-03.m4a` — 영재：나 향수광고 찍었어. 우리 집에 놀러와. 세트 하나 줄게.
- `ep003-youngjae-04.m4a` — 현재：향수얘기만 나오면 개짜증나 진짜
- `ep003-youngjae-05.m4a` — 영재：왜그래? 향수 때문에 짜증나는거지, 내가 짜증 나는건 아니지?
- `ep003-youngjae-06.m4a` — 현재：아니야. 나중에 얘기하자.
- `ep003-youngjae-07.m4a` — 영재：뭐해? 오늘 스케줄 있어? 우리 집으로와. 밥도 같이 먹자.
- `ep003-youngjae-08.m4a` — 현재：나중에 얘기해. 끊어.

以后新增剧情电话时继续使用“剧情编号-联系人-两位数顺序号”的方式命名，双方台词都计入顺序。
